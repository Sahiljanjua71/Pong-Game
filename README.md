# Pong Game in Python

A classic Pong game built using Python and Pygame. Control the right paddle and play against a simple AI opponent.

## Features

* Classic Pong gameplay
* Player-controlled paddle using keyboard
* AI-controlled opponent/Multiplayer
* Score tracking system
* Sound effects for collisions and scoring
* Countdown before each serve
* Smooth 60 FPS gameplay

## Controls

| Key          | Action           |
| ------------ | ---------------- |
| ↑ Up Arrow   | Move paddle up   |
| ↓ Down Arrow | Move paddle down |

## Requirements

* Python 3.x
* Pygame

Install Pygame:

```bash
pip install pygame
```

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/pong-game.git
```

2. Navigate to the project folder:

```bash
cd pong-game
```

3. Run the game:

```bash
python pong.py
```

## Gameplay

* The player controls the paddle on the right side.
* The AI controls the paddle on the left side.
* Score points when the ball passes your opponent.
* First to achieve the highest score wins.
